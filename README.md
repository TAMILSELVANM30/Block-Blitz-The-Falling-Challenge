# 🎮 Block Blitz – The Falling Challenge

**Block Blitz** is a simple browser-based arcade game where players must dodge falling red blocks using quick movements and reflexes. Stay alert, avoid collisions, and survive as long as possible!

## 🕹️ How to Play

- Use the **← Left Arrow** key to move left.
- Use the **→ Right Arrow** key to move right.
- Avoid the falling red obstacles.
- Survive without colliding with the obstacles!

## ✨ Features

- Simple and interactive gameplay
- Keyboard-based player movement
- Random falling obstacles
- Real-time collision detection
- Minimal and clean game interface

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start playing and dodge the obstacles!

## 🛠️ Technologies

- HTML
- CSS
- JavaScript

## 🎯 Objective

Test your reflexes, avoid every obstacle, and see how long you can survive!

**Stay sharp. Keep moving. Don't get hit!** 🔥
